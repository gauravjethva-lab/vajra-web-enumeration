# 🔒 Security Policy

## ⚠️ Ethical Use Only

VAJRA is a security research tool intended **exclusively** for:
- Authorized penetration testing
- Bug bounty programs
- Security research on systems you own
- CTF (Capture The Flag) challenges

**Unauthorized use against systems you do not own or have explicit permission to test is illegal and unethical.**

---

## 🛡️ Supported Versions

| Version | Supported |
|---------|-----------|
| Latest (main branch) | ✅ Yes |
| Older commits | ❌ No |

---

## 🐛 Reporting a Vulnerability

If you discover a security vulnerability in VAJRA itself:

1. **Do NOT open a public issue**
2. Open a **private** GitHub Security Advisory:
   - Go to the repo → Security → Advisories → New Draft Advisory
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

We will respond within **72 hours** and work with you to resolve it responsibly.

---

## 📋 Responsible Disclosure

We follow responsible disclosure principles:
- Vulnerabilities will be patched promptly
- Credit will be given to reporters (if desired)
- Public disclosure after fix is released
