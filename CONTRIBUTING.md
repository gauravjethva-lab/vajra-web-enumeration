## 📜 Code of Conduct

- Be respectful and constructive
- Only discuss **legal and ethical** use of security tools
- No offensive language or personal attacks

---

## 🛠️ How to Contribute

### 1. Fork & Clone
```bash
git clone https://github.com/YOUR_USERNAME/vajra-web-enumeration.git
cd vajra-web-enumeration
```

### 2. Create a Branch
```bash
git checkout -b feature/your-feature-name
# or
git checkout -b fix/your-bug-fix
```

### 3. Make Changes & Test
- Test on Kali Linux
- Make sure existing features still work
- Follow the existing code style

### 4. Commit
```bash
git add .
git commit -m "feat: add your feature description"
```

### 5. Push & Open PR
```bash
git push origin feature/your-feature-name
```
Then open a Pull Request on GitHub.

## 🧪 Development Setup

```bash
cd vajra
pip install -r requirements.txt
bash install.sh
python3 main.py
```

---

## ✅ Pull Request Guidelines

- Keep PRs focused — one feature/fix per PR
- Write clear commit messages (`feat:`, `fix:`, `docs:`, `refactor:`)
- Update README if needed
- Test before submitting

---

## 🐛 Reporting Bugs

Open an issue with:
- **OS & Python version**
- **Steps to reproduce**
- **Expected vs actual behavior**
- **Error output** (if any)

---

## 💡 Suggesting Features

Open an issue with the `enhancement` label and describe:
- What you want
- Why it would be useful
- Any implementation ideas

---

> ⚠️ All contributions must be for **ethical and legal** security testing purposes only.
